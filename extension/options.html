Must equal [target].target_id in config.toml.
Messages whose rendered timestamp is older than this are never forwarded.
A display name alone does not prove identity. The user id is read from the avatar image URL, so it is only usable when the author has a custom avatar. Apps/users with Discord's default avatar (e.g. Lbabinz, verified 2026-09-24) expose no id in the DOM: with a user id set, every one of their messages fails closed and is never forwarded. Grouped messages (no avatar shown) fail closed too. Leave this empty for such authors and use the display name plus a read-only channel instead.
The source server prohibits bots except those run by moderators. This extension does not install a server bot or use Discord APIs, but moderator acceptance of local automated monitoring is unresolved. Nothing here hides that the extension exists or what it does.
